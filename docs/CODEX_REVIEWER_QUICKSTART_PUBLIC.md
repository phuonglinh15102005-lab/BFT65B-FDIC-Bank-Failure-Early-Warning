# Codex review protocol for this public candidate

1. Read the original course rubric in `00_ASSIGNMENT/`, `AGENTS.md` and the 20+10 manuscript in `report/`.
2. Run unit tests, `run.py plan`, `run.py validate`, `tools/verify_released_aggregates.py` and the publication precheck. Report exit codes and actual counts.
3. Compare public 21-candidate grid and threshold CSV with Report Tables I5 and 5, verifying mean AP, temporal train/validation separation and the cost objective.
4. Validate source code path timing for exact t-1 and t-5 growth endpoints and separate this from historical filing receipt times.
5. Verify original `lock→claim→audit` digest certificate without opening test score rows; do not train or score test.
6. Check that source/cache Windows replay is not misstated as live FDIC API→model/test full E2E. Verify public GitHub from a signed-out browser and separately cloned copy once URL exists.
7. Inspect all PDF/DOCX pages, not only prose/metadata; confirm 20 main + 10 appendix and insert a real GitHub URL only after verification.
8. Treat any claim depending on unavailable historical raw bytes as NOT INDEPENDENTLY REPRODUCED; do not create substitute scores or assume missing evidence means the underlying experiment failed.

Never execute commands that retune the frozen model, test-score the held-out cohort or publish bank-level data.
