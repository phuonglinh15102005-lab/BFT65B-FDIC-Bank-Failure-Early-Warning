# Post-lock supplements E10–E12

E10 contains original development refit metrics and outcome-group medians, plus label-free clean-panel RBCRWAJ persistence. E11 contains ROC-AUC, AP lift, era medians and matched-CERT counts. E12 contains positive lagged-equity subgroup metrics, distinct-event eligibility and illustrative random K-fold overlap. These are post-lock nonselective diagnostics; capital-reporting checks read the unlabeled clean panel, not test labels or scores. No diagnostic changes the registered model, threshold or locked test evaluation.

Run `python -B tools/verify_e10_workload_aggregate.py` and `python -B tools/verify_e11_e12_aggregate.py` to check the public archived outputs. Refits on original Windows inputs require the private Parquet snapshots.
